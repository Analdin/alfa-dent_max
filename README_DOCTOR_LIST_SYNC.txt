# AlfaDent — синхронизация списка врачей

В архиве находятся два обновлённых Python-файла и текстовый список для ручного переноса:

- `bot_telegram.py` — версия на базе последнего переданного Telegram-исходника `bot_telegram_miniapp_final(1).py` (23.10.2026). Целевой путь на сервере: `/opt/alfadent_repo/bot_telegram.py`.
- `max_bot/max_bot.py` — версия на базе MAX-релиза `alfadent_max_client_update_final` (26.10.2026). Целевой путь на сервере: `/opt/alfa-dent_max/alfa-dent_max/max_bot/max_bot.py`.
- `DOCTORS_BLOCK.txt` — только новый массив `DOCTORS`, если в GitHub у вас лежат более свежие версии файлов и вы не хотите заменять их целиком.

В обоих Python-файлах массив `DOCTORS` совпадает с `const doctors` из Mini App: те же 19 врачей, тот же порядок. В обоих ботах установлено по 5 врачей на страницу. Обработчики, callback-идентификаторы и логика записи не менялись.

Синхронизированы только ФИО. Специальности, фото, стаж, цены и расписание не переносились: для части врачей Mini App прямо содержит неполные данные или пометки о необходимости уточнения.

Важно: перед заменой целых файлов сравните их с текущими файлами в GitHub. Если в репозитории есть более новые изменения, используйте `DOCTORS_BLOCK.txt` и замените только массив `DOCTORS` в актуальном файле. В MAX целевой файл именно `max_bot/max_bot.py`, не корневой `max_bot.py`.
