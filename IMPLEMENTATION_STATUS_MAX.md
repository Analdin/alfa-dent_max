# Состояние обновления MAX + существующего Mini App

## Реализовано в исходниках пакета

- MAX-бот использует актуальный API-хост `https://platform-api2.max.ru`.
- Главное меню отражает 10 разделов из клиентского ТЗ и не требует авторизации на `/start`.
- В MAX-боте исправлено название «Выпала коронка» и используется список из 9 услуг.
- Список акций общий с существующим Mini App: `web/assets/promotions.json` (10 предложений). Условия не дополняются выдуманными датами.
- Для акций есть карточка/условия и кнопка «Записаться по акции».
- В экстренном сценарии собираются проблема, комментарий, телефон и время.
- Убрана фиктивная запись из раздела «Мои визиты»; бот сообщает о неподключённой МИС и позволяет отправить запрос администратору.
- Заявка отмечает источник MAX/Telegram и включает явное уведомление, что время пока не забронировано.
- Mini App использует MAX Bridge + Telegram WebApp и отправляет платформу и `initData` на API.
- API проверяет HMAC MAX `WebAppData` и Telegram `initData`; проверка срока жизни ограничена 1 часом по умолчанию.
- CRM observers привязаны к отдельным `BITRIX_ADMIN_IDS`, не к идентификаторам пользователей Telegram.

## Проверки, выполненные локально

- Python-файлы прошли `py_compile`.
- Встроенный JavaScript Mini App прошёл `node --check`.
- В `promotions.json` ровно 10 акций с уникальными ID.
- Валидация MAX initData локально проверена на синтетическом токене: корректная подпись принята, изменённая — отклонена, обе формы данных (сырой initData и обёртка `WebAppData`) обработаны.

## Нужны внешние действия/данные

1. Залить файлы в текущий GitHub/Render-проект и выкатить деплой — из этого чата репозиторий и Render фактически не изменялись.
2. В MAX Partner Portal привязать текущему MAX-боту URL `https://alfadent-miniapp.onrender.com/miniapp.html`.
3. В Render и текущем сервисе MAX прописать свежий MAX-токен и Bitrix24 webhook. Старые значения раскрыты.
4. Указать точный `MAX_BOT_USERNAME`, Bitrix24 assigned-by ID и сопоставление MAX-admin ID → Bitrix24 ID.
5. Проверить настоящие webhook-события, передачу заявки в CRM и работу Mini App внутри MAX.
6. Подключить API МИС «Инфоклиника» для реальных слотов, визитов, переноса и отмены.

## Не заявляется как выполненное

- Нет подтверждения о боевом создании лида в Bitrix24.
- Нет подключённого SMS-провайдера: код `1234` временный.
- Нет интеграции с МИС.
- Нет фактически зарегистрированного webhook MAX или настроек MAX Partner Portal, так как доступ к кабинету не предоставлен.
