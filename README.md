# Альфа-Дент — MAX-бот

Актуальный самостоятельный обработчик MAX webhook. Mini App размещается в отдельном репозитории Telegram/Mini App и открывается по `MAX_MINIAPP_LINK`.

## Состав
- `max_bot/max_bot.py` — MAX webhook bot (Flask + Waitress).
- `max_bot/web/assets/promotions.json` — локальный резервный каталог акций.
- `requirements.txt` — зависимости MAX-бота.
- `.env.example` — перечень настроек без секретов.

## Установка
```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполнить .env на сервере, не коммитить его
python max_bot/max_bot.py
```

Для production лучше хранить значения в переменных окружения systemd/хостинга, а не в `.env`. Порт по умолчанию — 5000; перед публичным запуском настройте HTTPS reverse proxy и webhook в кабинете MAX.

## Важно
- `MAX_BOT_TOKEN` и `BITRIX24_WEBHOOK` намеренно не имеют встроенных значений. Старые значения были обнаружены непосредственно в исходном коде и должны быть отозваны/заменены.
- Задайте `MAX_WEBHOOK_SECRET` и тот же секрет в настройках webhook; в `.env.example` включено требование секрета.
- `MAX_MINIAPP_LINK` должен указывать на существующий Mini App, привязанный к боту в кабинете MAX.
- SMS OTP пока не подключён; демонстрационный код `1234` не является реальной проверкой номера.
- Интеграция с МИС не подтверждена: бот принимает пожелание по записи и передаёт обращение администратору/в CRM, но не резервирует реальное время.
- Удалены девять специалистов, отмеченных клиникой: семь уже отсутствовали в активном списке, ещё два удалены из текущего списка.
